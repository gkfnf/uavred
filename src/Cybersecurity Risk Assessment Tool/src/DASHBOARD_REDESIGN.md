# Dashboard 重新设计 - Bagels 风格

## 设计理念

参考 Bagels TUI 的美学和交互模式，将 Dashboard 重新设计为"活过来"的程序界面，强调：

1. **清晰的区域划分** - 使用细边框（border-2）替代圆角卡片
2. **聚焦系统** - 橙色边框高亮当前活跃区域
3. **紧凑的信息密度** - 最大化关键信息展示
4. **实时数据可视化** - ASCII sparklines 和动态指示器
5. **键盘优先** - 底部显示快捷键提示

## 布局结构

```

│ (漏洞)  │        Task Progress                       │                  │
│ 简单    │                                            │                  │
│ 滚动    │  • 任务列表（可选择，点击切换右侧AI详情）  │                  │
│ 列表    │  • 进度条                                   │   AI 详情区       │
│ 仅标题  │  • ETA 和状态                               │  (右侧固定)      │
│ 256px   │  • 总体完成度                               │  横跨整个高度    │

├─────────┴────────────────────────────────────────────┤  • 当前动作      │
│                                                      │  • 思考过程      │
```

## 三大区域详解

### v 区 (左上角 - 漏洞列表)
- **尺寸**: 256px 宽 × 256px 高 (w-64 × h-64)
- **位置**: 左上角小方块
- **内容**:
  - **极简设计**：仅显示漏洞标题的滚动列表
  - 每行显示：状态圆点 + 标题 + CVSS 评分
  - 支持滚动查看所有漏洞
  - 点击跳转到详细的 Vulnerabilities 视图
- **风格**: 
  - 超小字体 (text-[10px])
  - 最小化间距（py-1）
  - 状态圆点颜色区分严重程度
  - 无多余信息，只有标题

### p 区 (中上 - 任务进度)
- **尺寸**: flex-1 宽 × 256px 高
- **位置**: v 区右侧，占据中上部
- **内容**:
  - 任务列表（可选择）
  - 进度条可视化（颜色表示状态）
  - 当前步骤和 ETA
  - 任务状态图标
- **交互**:
  - 点击任务切换右侧 AI Agent 详情
  - 选中任务高亮显示（橙色边框）
  - 显示总体完成度

### i 区 (底部 - 流量监控)
- **空间**: 横跨整个底部（包括 v 区下方的空间，最大显示区域）
- **位置**: v 区和 p 区下方，从左到右完全占据
- **内容**:
  - TrafficQL 搜索框（强大的过滤语法）
  - 实时流量表格（完整 8 列显示）
    - Time, Method, Proto, Path, St, Size, Dur, Source
  - 异常标记（Zap icon 红色高亮）
  - 实时捕获统计和速率（pkts/s）
- **交互**:
  - 点击查看流量详情
  - TrafficQL 实时过滤
  - 显示捕获速率
  - 滚动查看历史流量
- **为什么最大？**
  - 流量数据需要 8 列完整展示
  - 横向空间最重要
  - 纵向也需要足够高度显示多行记录
  - 是实时监控的核心功能

### 右侧 (AI Agent 详情)
- **宽度**: 384px (w-96)
- **内容**:
  - 当前 AI 动作（带动画加载器）
  - 置信度进度条
  - 思考过程（编号列表）
  - 发现结果（带状态符号: ✓ ⚠ ⧗）
  - 下一步计划
  - ASCII Sparkline 活动图
- **动态性**:
  - 根据 p 区选择的任务切换
  - 实时更新 AI 执行状态
  - 脉冲动画表示活跃状态

## Bagels 风格元素

### 1. 区域标识符
每个区域左上角显示单字母标识符（v, i, p）在小方块中：
```tsx
<div className="w-6 h-6 rounded flex items-center justify-center bg-slate-800/50">
  <span className="text-xs font-mono font-bold text-slate-400">v</span>
</div>
```

### 2. 聚焦边框
活跃区域使用橙色边框高亮：
```tsx
border-2 transition-all
${focusPanel === 'left' ? 'border-orange-500/80' : 'border-slate-700/40'}
```

### 3. 底部按键提示栏
橙色背景的快捷键提示：
```tsx
<div className="border-t-2 border-orange-500/80 bg-orange-500/10 px-3 py-1.5">
  <div className="flex items-center gap-4 text-[9px] font-mono">
    <div className="flex items-center gap-1">
      <span className="px-1.5 py-0.5 rounded bg-orange-500/20 text-orange-400">v</span>
      <span className="text-slate-500">Vulnerabilities</span>
    </div>
    ...
  </div>
</div>
```

### 4. ASCII Sparkline
使用 Unicode 字符绘制活动图表：
```tsx
const generateSparkline = (length: number, seed: number) => {
  const bars = ['▁', '▂', '▃', '▄', '▅', '▆', '▇', '█'];
  // ... 生成算法
};

// 显示
<div className="font-mono text-xs text-cyan-400 tracking-wider">
  {generateSparkline(48, Date.now() / 1000)}
</div>
```

### 5. 实时状态指示器
脉冲动画的圆点：
```tsx
<div className="w-1.5 h-1.5 rounded-full bg-red-400 animate-pulse" />
<span className="text-red-400 font-mono">LIVE</span>
```

## 颜色方案

- **边框**: slate-700/40 (未聚焦), orange-500/80 (聚焦)
- **背景**: slate-950 (主背景), slate-900/50 (header/footer)
- **文字**: 
  - 标题: slate-300
  - 正文: slate-400, slate-500
  - 次要: slate-600, slate-700
- **状态色**:
  - Critical: red-400
  - High: orange-400
  - Medium: yellow-400
  - Success: emerald-400
  - AI/Active: purple-400
  - Traffic: cyan-400

## 字体尺寸

遵循紧凑型设计原则：
- 超小: text-[8px]
- 极小: text-[9px]
- 小: text-[10px]
- 标准: text-[11px]
- 标题: text-xs (12px)

## 交互流程

1. **Tab 键切换聚焦** - 在 v/i/p 区域间循环
2. **v 键直接跳转** - 聚焦漏洞区域
3. **i 键直接跳转** - 聚焦流量区域
4. **p 键直接跳转** - 聚焦任务区域
5. **点击任务** - 切换右侧 AI Agent 详情
6. **Esc 键** - 关闭弹窗/取��操作

## 空间分配策略

为什么这样设计？

1. **漏洞区域小 (v区 - 256×256px)**: 
   - 用户只需要快速扫一眼发现的漏洞标题
   - **极简设计**：仅列表，无卡片，无复杂信息
   - 详细信息通过点击进入专门的 Vulnerabilities 视图查看
   - 小方块足以显示滚动列表

2. **任务进度居中上部 (p区 - flex-1 × 256px)**:
   - 需要足够宽度显示任务名称、资产、进度条
   - 256px 高度可以容纳 3-4 个任务
   - 用户可以快速切换查看不同任务的 AI 执行情况
   - 选中任务会改变右侧 AI 详情显示

3. **流量监控占据最大空间 (i区 - 横跨整个底部)**:
   - 流量数据信息密度高，需要 8 列完整显示
   - **横跨底部包括 v 区下方空间** - 充分利用所有可用空间
   - 横向宽度让表格所有列清晰可见
   - 纵向高度最大化，可以同时看到更多流量记录
   - 实时监控是核心功能，值得最大显示区域
   - TrafficQL 过滤功能强大，需要空间展示结果

4. **AI 详情固定右侧 (384px × 100%)**:
   - 横跨整个右侧高度，始终可见
   - 实时更新，显示选中任务的 AI 执行细节
   - 384px 宽度足够显示：
     - 当前动作
     - 思考过程（带编号）
     - 发现结果（带状态符号）
     - 下一步计划
     - Sparkline 活动图

## 对比传统设计

### 之前（第一版）
- 三栏等宽布局
- 漏洞区域过大（w-72 = 288px）
- 流量区域在中间被压缩
- 任务进度在底部空间受限

### 现在 (Bagels 风格 + 优化布局)
- **v 区**: 左上小方块，256×256px，仅显示关键威胁
- **p 区**: 中上横条，256px 高，任务列表清晰可见
- **i 区**: 底部横跨，最大空间，流量数据完整展示
- **右侧**: 固定 AI 详情，实时同步
- 使用细边框分隔，不用圆角卡片
- 紧凑的间距，信息密度高
- 小字体 font-mono
- 区域标识符（v, i, p）
- 橙色聚焦系统
- 底部快捷键提示栏
- ASCII sparkline 图表
